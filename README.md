Mi nombre es [Danilo Andrés Niebles Morrón] y actualmente estudio el programa de [Integración en ].

Este repositorio contiene información y archivos relacionados con mi proyecto Cositas, un emprendimiento dedicado a la distribución y venta de accesorios y productos novedosos. El objetivo del proyecto es ofrecer variedad, calidad y una experiencia de compra cercana y confiable para los clientes.

A través de este proyecto también puedo poner en práctica conocimientos relacionados con la tecnología, el diseño y la creación de contenido digital.
